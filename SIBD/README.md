# Base de dados de plataforma de música em PLSQL
Desenvolvimento de um sistema com o objetivo de criar uma base de dados de um site fictício onde o utilizador pode guardar artistas e álbuns musicais, bem como canções, faixas e informações detalhadas dos mesmos.

# Estrutura

1. **Diagrama EA** Esquematização e desenho das entiadades, atributos e dependências
2. **Criação de tabelas** Criação de tabelas com base no Diagrama EA anterior
3. **Queries** Conjunto de queries para exercitar o funcionamento das tabelas
4. **PLSQL** Código PLSQL para criação e manipulação de tabelas
